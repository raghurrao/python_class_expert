# Capstone Project: End-to-End Customer Attrition Predictor

This directory contains the final Week Capstone Project files:
* `generate_data.py`: Creates mock churn dataset.
* `day85_eda.py`: Performs customer statistics calculations.
* `day86_pipeline.py`: Builds sklearn preprocessing pipeline.
* `day87_training.py`: Runs cross-validation grid search and serializes best model.
* `day88_app.py`: Serves FastAPI server predictions.
* `Dockerfile` & `docker-compose.yml`: Builds Docker container service.
