# Day 9: Data Cleaning & Type Casting

Data cleaning is the most common task in data science. Today we learn how to handle missing values and duplicates.

## Core Concepts
* `isna()`, `isnull()`: Find missing values.
* `fillna()`: Impute missing values with a default or statistic (mean, median).
* `dropna()`: Drop rows/columns containing missing values.
* `duplicated()`, `drop_duplicates()`: Detect and remove duplicate records.
* `astype()`: Convert column types.
