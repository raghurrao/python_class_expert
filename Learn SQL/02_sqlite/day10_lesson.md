# Day 10: Relational Joins Masterclass

Joins combine columns from one or more tables based on related values.

---

## 1. Join Types

1. **`INNER JOIN`**: Returns rows only when key matches exist in both tables.
2. **`LEFT JOIN`**: Returns all rows from left table, plus matched right table rows (NULL if no match).
3. **`CROSS JOIN`**: Cartesian product of both tables.
4. **`SELF JOIN`**: Joining a table to itself (e.g. Employee to Manager hierarchy).
