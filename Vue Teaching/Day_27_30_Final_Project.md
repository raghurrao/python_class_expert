# Day 27-30: Final Capstone Project

You made it to the end of the month! It is time to prove your Vue expertise. 

## 🎯 Goal
Build a Full-Stack Clone of your choice (e.g., a Twitter clone, a simplified Reddit clone, or an advanced E-commerce app). 
You can choose to build this as a standard **Vite SPA** or use **Nuxt 3**.

## 📋 Requirements
Your application must include the following features:

1. **Routing:** Multiple pages with dynamic routes (e.g., viewing a specific user profile or a specific post).
2. **State Management:** Use Pinia to manage global application state (like the current user, or a cache of loaded posts).
3. **Data Fetching:** Connect to a real public API (like `https://dummyjson.com/` or `https://jsonplaceholder.typicode.com/`), or set up your own mock backend using Firebase/Supabase.
4. **Component Architecture:** Break your UI down into small, reusable components. Use props and emits effectively.
5. **Composables:** Write at least one custom composable to abstract logic (e.g., `useAuth` or `useTheme`).
6. **Styling:** Make it look great using standard CSS, or a framework like Tailwind CSS (which integrates perfectly with Vite/Nuxt).

## 🚀 Deployment
Once your app is complete, show it to the world!
- If using Vite: Deploy to **Netlify** or **Vercel** by linking your GitHub repository.
- Run `npm run build` locally to see how Vue compiles your code into optimized static assets in the `/dist` folder.
