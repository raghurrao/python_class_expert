# 30-Day SQL Study Plan

Study 1–2 hours daily. Suggested allocation: theory 25 min, demonstration 20 min, independent practice 45 min, revision 10 min. Add time as needed for assessment days.

| Day | Focus |
|---:|---|
| 01 | Database fundamentals, relational tables, SELECT, FROM, WHERE |
| 02 | CREATE TABLE, SQLite data types, primary keys, foreign keys |
| 03 | INSERT, UPDATE, DELETE |
| 04 | SELECT, DISTINCT, column aliases, filtering |
| 05 | Comparison operators, logical operators, ORDER BY, LIMIT |
| 06 | LIKE, BETWEEN, IN, IS NULL |
| 07 | Revision and practical assessment |
| 08 | Aggregate functions: COUNT, SUM, AVG, MIN, MAX |
| 09 | GROUP BY |
| 10 | HAVING |
| 11 | INNER JOIN and multi-table joins |
| 12 | LEFT JOIN, RIGHT JOIN, FULL OUTER JOIN, CROSS JOIN, with SQLite compatibility explained |
| 13 | Self joins and natural joins |
| 14 | Revision and practical assessment |
| 15 | Subqueries in SELECT, FROM, and WHERE |
| 16 | Correlated subqueries |
| 17 | EXISTS and NOT EXISTS |
| 18 | ANY, ALL, IN, NOT IN, and SQLite compatibility |
| 19 | UNION, UNION ALL, INTERSECT, EXCEPT |
| 20 | Views, CTEs, recursive CTEs |
| 21 | Revision and practical assessment |
| 22 | Constraints and referential integrity |
| 23 | Indexes and index design |
| 24 | Query execution plans and optimization |
| 25 | Transactions, ACID, COMMIT, ROLLBACK, SAVEPOINT |
| 26 | Triggers and auditing |
| 27 | Stored procedures and user-defined functions, explaining SQLite limitations |
| 28 | Window functions: ROW_NUMBER, RANK, DENSE_RANK, LAG, LEAD, running totals |
| 29 | End-to-end university database project |
| 30 | Comprehensive SQL assessment and final project evaluation |

## Milestones

- Week 1: read and modify data confidently.
- Week 2: summarize and combine related data.
- Week 3: compose subqueries, sets, and reusable query blocks.
- Week 4: reason about integrity, performance, transactions, and analytics.
