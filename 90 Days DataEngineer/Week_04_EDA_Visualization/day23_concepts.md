# Day 23: Seaborn Statistical Plots

Seaborn is built on top of Matplotlib and integrates closely with Pandas. It provides beautiful default styles and statistical charts.

## Core Plots:
* `sns.scatterplot()`: Relational coordinate plotting.
* `sns.histplot()`: Distributive frequency plotting.
* `sns.boxplot()`: Categorical distribution showing quartiles.
* `sns.heatmap()`: Matrix style correlation plotting.
