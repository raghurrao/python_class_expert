# 30-Day PyTorch Mastery Curriculum

## Phase 1: PyTorch Foundations
- **Day 1**: PyTorch Introduction (Tensors, NumPy vs PyTorch, CPU vs GPU)
- **Day 2**: Tensors (Creation, shape, dtype, device, reshaping)
- **Day 3**: Tensor Operations (Arithmetic, matrix multiplication, reduction, broadcasting)
- **Day 4**: Tensor Shapes (Deep dive into [batch, channels, height, width], etc.)
- **Day 5**: Autograd (Computational graphs, `requires_grad`, backward pass)
- **Day 6**: Linear Regression From Scratch (Implementing regression with Tensors & Autograd)
- **Day 7**: Weekly Project - House Price Prediction using PyTorch

## Phase 2: Neural Network Fundamentals
- **Day 8**: Neural Networks (Neurons, layers, parameters, weights, bias)
- **Day 9**: `torch.nn` (Deep dive into `nn.Module`, `nn.Linear`, `nn.Sequential`)
- **Day 10**: Loss Functions (MSE, MAE, Cross Entropy, BCE)
- **Day 11**: Optimizers (SGD, Momentum, Adam, AdamW, LR updates)
- **Day 12**: Training Loops (Forward, loss, zero_grad, backward, step)
- **Day 13**: Validation & Evaluation (Train vs Val vs Test, confusion matrices, F1 score)
- **Day 14**: Project - Customer Churn Prediction Neural Network

## Phase 3: Advanced Training
- **Day 15**: Overfitting & Regularization (Dropout, weight decay, early stopping)
- **Day 16**: Learning Rate & Training Optimization (Scheduling, StepLR, ReduceLROnPlateau)
- **Day 17**: Dataset & DataLoader (Batching, shuffling, `num_workers`, custom datasets)
- **Day 18**: Model Saving & Loading (`state_dict`, saving checkpoints)
- **Day 19**: GPU / CUDA (Device management, `.to(device)`)
- **Day 20**: Debugging PyTorch (Diagnosing shape, device, NaN, and gradient errors)
- **Day 21**: Project - Fashion-MNIST Image Classifier

## Phase 4: Computer Vision
- **Day 22**: CNN Fundamentals (Convolution, filters, stride, pooling visually)
- **Day 23**: CNN With PyTorch (`nn.Conv2d`, `nn.MaxPool2d`)
- **Day 24**: CNN Project (Image classifier with real-world dataset)
- **Day 25**: Transfer Learning (Pretrained models, feature extraction, fine-tuning)

## Phase 5: Modern Deep Learning
- **Day 26**: Embeddings & Sequence Models (RNN/LSTM intuition, word embeddings)
- **Day 27**: Attention (Query, Key, Value, Self-attention scores)
- **Day 28**: Transformers (Architecture, positional encoding, multi-head attention)

## Phase 6: Production + Final Project
- **Day 29**: Production PyTorch (Inference pipelines, `torch.no_grad()`, TorchScript concepts)
- **Day 30**: Capstone Project (End-to-End ML System design, training, evaluation, inference)
