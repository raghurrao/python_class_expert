# 30-Day `awk` Mastery Roadmap

Welcome to your 30-Day `awk` Learning Journey! Track your daily progress by checking off completed lessons.

---

## Week 1: Fundamentals & Basic One-Liners
- [ ] **Day 01:** Introduction to `awk` (Syntax, structure `awk 'pattern { action }'`, running one-liners)
- [ ] **Day 02:** Fields & Delimiters (`$0`, `$1`, `$2`, `$NF`, custom field separators `-F`)
- [ ] **Day 03:** Built-in Variables (`NR`, `FNR`, `NF`, `FS`, `OFS`, `RS`, `ORS`)
- [ ] **Day 04:** Patterns & Matching (Regex matching `~`, `!~`, comparison operators `==`, `<`, `>`)
- [ ] **Day 05:** Actions & Formatting (`print` vs `printf`, column alignment, custom output separators)
- [ ] **Day 06:** BEGIN & END Blocks (`BEGIN { ... }`, `END { ... }`, pattern ranges `/start/, /stop/`)
- [ ] **Day 07:** Week 1 Review & Practical Exercises (Field extraction & tabular reports)

## Week 2: Arithmetic, Control Flow & String Functions
- [ ] **Day 08:** Arithmetic & Aggregations (Math operators, sums, averages, min/max calculation)
- [ ] **Day 09:** Conditional Statements (`if`, `else if`, `else`, ternary operators `? :`)
- [ ] **Day 10:** Loops in `awk` (`for`, `while`, `do-while`, `break`, `continue`, `next`)
- [ ] **Day 11:** String Manipulation Part 1 (`length()`, `substr()`, `index()`, `split()`)
- [ ] **Day 12:** String Manipulation Part 2 (`sub()`, `gsub()`, `match()`, `tolower()`, `toupper()`)
- [ ] **Day 13:** Math & Numeric Functions (`int()`, `sqrt()`, `rand()`, `srand()`, `exp()`, `log()`)
- [ ] **Day 14:** Week 2 Review & Challenge (Calculating CSV statistics & formatting reports)

## Week 3: Associative Arrays, Multi-File Processing & Functions
- [ ] **Day 15:** Introduction to Associative Arrays (`arr[key] = val`, key-value counting)
- [ ] **Day 16:** Array Operations & Iteration (`for (key in arr)`, checking keys, `delete`)
- [ ] **Day 17:** Multi-Dimensional Arrays & `split()` (`arr[i, j]`, dynamic array creation)
- [ ] **Day 18:** Multi-File Processing (`FILENAME`, `NR == FNR`, merging datasets by key lookup)
- [ ] **Day 19:** Advanced Regular Expressions (Capture groups, sub/gsub regex tricks)
- [ ] **Day 20:** User-Defined Functions (`function name(args) { ... }`, scope & arguments)
- [ ] **Day 21:** Week 3 Review & Challenge (Log aggregation & frequency tabulation)

## Week 4: Real-World Use Cases, Shell Integration & Capstone
- [ ] **Day 22:** Web Server Log Analysis (Parsing Apache/Nginx access logs, IP stats, status codes)
- [ ] **Day 23:** System Performance Log Parsing (Parsing `ps aux`, `df -h`, `free`, `/proc` metrics)
- [ ] **Day 24:** Handling Complex Record & Field Separators (Multi-line records `RS=""`, custom RS)
- [ ] **Day 25:** Standalone `awk` Scripts & Shell Variables (`#!/usr/bin/awk -f`, `-v var=val`)
- [ ] **Day 26:** Shell Pipeline Mastery (Combining `awk` with `grep`, `sed`, `sort`, `uniq`, `cut`)
- [ ] **Day 27:** Custom Text Dashboards & Reporting (ASCII progress charts, summary tables)
- [ ] **Day 28:** System Administration Automation (Disk threshold alerts, security login audit)
- [ ] **Day 29:** Complex Data Transformation (Converting key-value logs to JSON/CSV)
- [ ] **Day 30:** Final Capstone Project & Graduation (End-to-End Automated Log & System Health Analyzer)
